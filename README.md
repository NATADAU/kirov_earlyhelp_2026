# Фестиваль ранней помощи · Киров · 28–29 сентября 2026

Мобильный лендинг программы фестиваля.

## Что есть
- расписание по двум дням;
- отдельное отображение параллельных мастер-классов;
- поиск по темам и спикерам;
- список спикеров с их выступлениями;
- тематические фильтры;
- «Моя программа» со звёздочками и сохранением выбора в браузере телефона;
- адаптивная вёрстка без внешних библиотек.

## Файлы
- `index.html` — страница;
- `styles.css`, `extra.css` — стили;
- `data-day1.js`, `data-day2.js` — программа;
- `app.js` — интерактивность.

## Публикация на GitHub Pages
В репозитории откройте **Settings → Pages** и выберите **Deploy from a branch → main → /(root)**. После сохранения сайт будет доступен по адресу `https://natadau.github.io/kirov_earlyhelp_2026/`.
